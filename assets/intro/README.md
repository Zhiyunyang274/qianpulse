# Intro media

Optional replacement media for the QianPulse cinematic intro:

- `story_01.jpg` — Guizhou bridge network
- `story_02.jpg` — bridge lifecycle / long-term service
- `story_03.jpg` — digital maintenance system
- `story_04.mp4` — traffic, bridge deck, or vehicle sensing footage
- `reveal.jpg` — QianPulse reveal background

Supported image formats: JPG, JPEG, PNG, WebP. Supported video formats: MP4, WebM.
When a file is absent, the app uses its built-in mountain-and-bridge SVG fallback.
